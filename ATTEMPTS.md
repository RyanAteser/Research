# Attempts

One entry per frozen model. The entry is committed before the model's first test week. A changed model is a new entry and a new 13-week test.

Each entry states:

- **ID and freeze date**
- **Model commit**: the hash of the code and parameters being tested
- **Inputs**: every data source the model reads
- **First and last test chart dates**
- **Why this attempt**: the finding that motivates it
- **Result**: filled in after week 13 and never edited afterwards
